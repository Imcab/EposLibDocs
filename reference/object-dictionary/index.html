    Object dictionary#

    Every object of the EPOS4 that EposLib names, generated from the device EDS (EPOS4 Module 50/15). Use the constants with Epos4::ReadObject() / WriteObject():

    std::int16_t raw{};
motor.ReadObject(epos4::od::At(epos4::od::cia402::kTorqueActualValue), raw);
motor.ReadObject(epos4::od::maxon::kMotorData_NominalCurrent, nominal);  // an Entry

    An index constant (std::uint16_t) needs od::At(index, subindex); a sub-index constant is already an od::Entry. Code written against od::cia402 works with any CiA 402 drive; the maxon namespaces do not.
