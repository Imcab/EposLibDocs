# Cyclic velocity

A trapezoidal velocity profile generated by the program, one setpoint per SYNC, with the drive's velocity loop making the motor follow it - the loop a rover wheel runs. When the target returns to zero the drive brakes actively, and the program waits for standstill before disabling.

## Key points

- The interpolation time period is set to the SYNC period.
- `EnterCyclicVelocityMode()` starts from 0 rpm: no jump.
- `StageTargetVelocity()` is lock-free; `IsCyclicHealthy()` is checked every cycle.
- `sleep_until` on an absolute time keeps the period exact.

## Step by step

1. **PDOs are mandatory** for the cyclic modes - the program checks `IsPdoActive()` and stops otherwise.
2. **Interpolation period = SYNC period** (`CyclicConfigs::interpolationTimePeriodMs = 10`), or the drive steps between setpoints.
3. **`EnterCyclicVelocityMode()`** switches to mode 9 once (SDO) and starts publishing 0 rpm on every SYNC.
4. **The loop** computes the trapezoid, stages it (an atomic store), checks `IsCyclicHealthy()`, and sleeps until the next absolute 10 ms tick.
5. **Braking:** with the target at 0 the drive's velocity loop brakes actively; the program waits until the cached velocity is under 10 rpm before `ExitCyclicMode()` and `Disable()`.

```bash

  install/eposlib/share/eposlib/config/epos4_network/master.dcf can0 2 [rpm]
```
