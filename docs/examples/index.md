# Examples

Fourteen complete programs, each one a single `.cpp` file. They live in the
[`examples/`](https://github.com/Imcab/EposLibDocs/tree/main/examples) folder of the
documentation repository as a `colcon` package, `eposlib_examples`, and every one of them is
**compiled and run against `epos4_sim` before the documentation is published** - except
Profile Velocity, which the simulator does not model and is only compiled. The output shown on each page is the real
output of that run.

| Example | Shows |
|---|---|
| [Device information](device-info.md) | boot status, identity, PDO check, state, faults, supply, motor data - read-only |
| [Profile position](profile-position.md) | absolute and relative moves, raw units and angles, waiting for the target |
| [Profile velocity](profile-velocity.md) | a velocity with a drive-generated ramp |
| [Cyclic velocity](cyclic-velocity.md) | a trapezoidal velocity profile generated by the program, active braking |
| [Cyclic torque](cyclic-torque.md) | torque in N m, with a velocity limit |
| [Cyclic position](cyclic-position.md) | following a trajectory in degrees at the output |
| [Homing](homing.md) | input mapping, homing configuration, `Home()` and `SetPosition()` |
| [Multiple drives](multi-drive.md) | two wheels on one bus, commanded on the same SYNC |
| [Fault monitor](fault-monitor.md) | emergency callback, telemetry, fault recovery |
| [Configuration](configuration.md) | read everything, change part, save |
| [Encoder setup](encoder-setup.md) | sensor slots, resolution, angles at the output |
| [Digital I/O and touch probe](digital-io.md) | inputs, outputs, analog channels, latching the index position |
| [Step response](step-response.md) | record target vs. actual to CSV, for tuning and plotting |
| [Telemetry logger](telemetry-logger.md) | supply, temperature, current, I²t, state and EMCY to CSV |

## Building them

```bash
cd ~/ros2_ws/src
git clone https://github.com/Imcab/EposLibDocs.git
ln -s EposLibDocs/examples eposlib_examples      # or copy the folder
cd ~/ros2_ws
colcon build --packages-up-to eposlib_examples
source install/setup.bash
```

Every example takes the master DCF as its first argument, then the interface and the
node-ID:

```bash
DCF=install/eposlib/share/eposlib/config/epos4_network/master.dcf
ros2 run eposlib_examples device_info $DCF can0 2
```

Without ROS, run the binaries from `install/eposlib_examples/lib/eposlib_examples/`.

## Running them against the simulator

```bash
sudo modprobe vcan
sudo ip link add dev vcan0 type vcan && sudo ip link set up vcan0
CFG=install/eposlib/share/eposlib/config/epos4_network
install/eposlib/lib/eposlib/epos4_sim $CFG/epos4.eds 2 vcan0 &
ros2 run eposlib_examples profile_position $CFG/master.dcf vcan0 2
```

`scripts/check_examples.sh` in the documentation repository does all of it - build, then
each example against a fresh simulator - inside a container, without touching the host's
network.

!!! warning "On hardware"
    The examples move the motor. Run them first with the motor free to turn and nothing
    attached, and keep the power switch within reach.
